# Фирменный знак `yandex-wiki-search-mcp`

Один непрерывный штрих, сложенный четыре раза. Складка — от логотипа MCP (там это
сложенная лента-соединение), горизонтальные прогоны — строки вики-страницы.
Скруглённые торцы и радиус поворота ровно в половину межстрочного шага держат
всю форму на одной геометрической сетке.

Знак нарисован с нуля: он не воспроизводит ни марку Яндекс Вики, ни логотип MCP —
берёт от них только пластику (скруглённые торцы, стопка горизонталей, синяя гамма).

---

## Что здесь лежит

```
logo-primary.svg          основной, белый знак на синем скруглённом квадрате
                          (используется в README и реестрах)
logo-mono.svg             знак без подложки, stroke="currentColor"
lockup-package.svg        знак + yandex-wiki-search-mcp (JetBrains Mono),
                          текст тёмный — только для светлого фона
social-preview.svg        1280×640, обложка репозитория (Open Graph)
icon-512.png              растр основного знака — иконка MCPB-бандла
                          (manifest.json) и реестра MCP (server.json)
build.py                  генератор SVG (вся геометрия параметрами)
```

Это рабочее подмножество. Полный набор — тёмные/светлые варианты, круглая
подложка под аватары, компактный знак (3 сгиба) для 48 px и мельче, лок-апы,
фавиконы — собирается из `build.py` (см. «Пересборка»).

## Палитра

| роль | hex | где |
|---|---|---|
| `blue` | `#2A4DDB` | основной, подложка и знак на светлом |
| `ink` | `#0E1530` | тёмная подложка, основной текст |
| `sky` | `#DDE4FF` | светлая подложка |
| `mist` | `#9FB2FF` | подзаголовок на тёмном |
| `white` | `#FFFFFF` | знак на цветном |

## Как использовать

**В README.** В `<img>` SVG живёт изолированным документом — `currentColor`
у `logo-mono.svg` там не наследуется от страницы, поэтому берите
`logo-primary.svg`: он несёт собственную подложку и одинаково работает на
светлой и тёмной теме. URL — абсолютный, чтобы картинка рендерилась и на
PyPI, где относительные пути ломаются:

```html
<img src="https://raw.githubusercontent.com/dlbolshov/yandex-wiki-search-mcp/main/docs/assets/logo/logo-primary.svg" alt="yandex-wiki-search-mcp logo" width="104">
```

**В реестрах MCP** (glama.ai, mcp.so, официальный registry) обычно просят
квадратный PNG — берите `icon-512.png` (он же прописан в `manifest.json`
и `server.json`). Собран из `logo-primary.svg` через cairosvg:

```bash
uv run --no-project --with cairosvg python -c "import cairosvg; cairosvg.svg2png(url='logo-primary.svg', write_to='icon-512.png', output_width=512, output_height=512)"
```

**Обложка репозитория.** GitHub: Settings → Social preview → загрузить растр
`social-preview.svg` (1280×640 PNG, той же командой выше).

**Фавикон.** 32 px и мельче собирайте с компактного знака (3 сгиба, есть в
`build.py`): четыре сгиба на таком размере схлопываются в кашу.

**Охранное поле** — не меньше высоты одного прогона знака (⅛ стороны подложки)
со всех сторон. Знак не растягивать, не перекрашивать штрих в градиент, не
класть на пёстрый фон без подложки.

## Пересборка

Вся геометрия — константы в начале `build.py`; поменять число сгибов, толщину
штриха или палитру можно, не трогая пути. Полный набор собирается в `dist/`
рядом со скриптом (переопределяется через `LOGO_OUT`); `dist/` и `fonts/`
в git не попадают — в репозитории живёт только рабочее подмножество выше.

```bash
cd docs/assets/logo
mkdir -p fonts
curl -L -o fonts/Inter.ttf "https://raw.githubusercontent.com/google/fonts/main/ofl/inter/Inter%5Bopsz%2Cwght%5D.ttf"
curl -L -o fonts/JetBrainsMono.ttf "https://raw.githubusercontent.com/google/fonts/main/ofl/jetbrainsmono/JetBrainsMono%5Bwght%5D.ttf"
uv run --no-project --with cairosvg --with fonttools --with uharfbuzz python build.py
```

Текст в лок-апах переведён в кривые (Inter и JetBrains Mono, обе SIL OFL 1.1),
шрифты нужны только генератору — готовые SVG самодостаточны.

## Про товарные знаки и лицензию

- «Яндекс», «Яндекс Вики» — товарные знаки ООО «Яндекс». В названии проекта и в
  лок-апе они использованы номинативно: чтобы сказать, с каким сервисом работает
  сервер. Оригинальная иконка Яндекс Вики в ассетах не используется и не
  перерисовывается — знак специально сделан самостоятельным; так должно
  оставаться и впредь.
- Оба README несут строчку «неофициальный проект» в шапке и раздел
  «Товарные знаки» в подвале — при изменениях брендинга обновляйте и их.
- Значок «работает по MCP», если он когда-нибудь понадобится, — только
  официальные ассеты и правила с сайта Model Context Protocol; их логотип
  в этот знак не вплетён и вплетаться не должен.
- Файлы знака распространяются на тех же условиях, что и репозиторий
  (Apache-2.0, см. [LICENSE](../../../LICENSE)).
